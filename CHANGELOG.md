# Changelog

Notable changes to KAFRA. The project follows [Semantic Versioning](https://semver.org/). The `.kafra` format has its
own version number, described in [FORMAT.md](FORMAT.md).

## [Unreleased]

## 0.1.0

The first release.

- `kafra store`, `info`, `list`, `extract` and `verify`.
- Version 1 of the `.kafra` format, with the raw, image, sound, ground and altitude transforms.
- Reads GRF versions 0x200 and 0x300, including EUC-KR paths and DES-scrambled entries.
